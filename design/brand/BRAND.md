# bora.py — brand

## Name

**bora.py** (say it "bora dot pie"). Always lowercase, always with the dot.

- **bora** — from *borahae*, "I purple you": love that stays. The app's promise is the same — no streaks, no decay, no guilt; every checkpoint waits for you.
- **.py** — every lesson ends as a real Python file she writes and runs in her own terminal. The name is literally a file she could make.

## Mark

`logo.svg` — a terminal prompt on the red square: a chevron (the prompt, and the arrow to the next checkpoint) plus a block cursor (your turn to type). It encodes the product's core rule: **the app never runs code — she does.**

Geometry: 64×64 square, zero radius, squared line caps. No gradients, no rounding, no shadows.

## Variants

- **Primary:** red field `#ec3013` (`--color-accent`), glyphs `#f3f2f2` (`--color-bg`).
- **Ink:** field `#201e1d` (`--color-text`), glyphs `#f3f2f2`. For places red would compete with the poster/celebration field.
- **Mono:** transparent field, glyphs in `--color-text`. Favicon at small sizes may drop the cursor block.

## Wordmark

Set live in Archivo (the system face), never as outlines:

- `bora` — Archivo 900, lowercase, `--color-text`
- `.py` — same weight/size, `--color-accent-700`
- Letter-spacing 0.01em; sits flush left, baseline-aligned with the mark.

Lockup: mark + 8px gap + wordmark, mark height = cap height × 1.2 (e.g. 22px mark with 19px wordmark).

## Rules

- Clear space around the lockup ≥ the cursor block's width.
- Minimum mark size 16px.
- Never round corners, tint, add gradients, or rotate.
- Never use official BTS logos, photography, or lyric text near the brand — fan-culture references live in content, facts only.
